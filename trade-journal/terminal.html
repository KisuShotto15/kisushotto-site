REGLAS DEL SISTEMA
Endurecer una regla aplica al instante. Aflojarla queda en espera 24 horas: una decision tomada en caliente no tiene efecto ese dia. Los limites duros (riesgo maximo 2%) no se pueden pasar.
CALENDARIO ECONOMICO
Se descarga solo cada 6 horas (eventos de alto impacto en USD). Puedes agregar dias a mano; quitar no se puede.
CUENTAS CONECTADAS
Crea la API key con permiso de lectura + trading (spot y futuros) y sin permiso de retiro. Usa una subcuenta dedicada solo a este sistema. Las llaves se guardan cifradas. Cada cuenta empieza en simulacion: el terminal calcula todo pero no envia ordenes ni el guardian corrige. 

    

  


  
  

    EL PROCESO
    

      
Antes de la sesion

      
    
        
  1. Duerme y come. Si estas cansado, enfermo o alterado, pulsa "Bloquearme por hoy".
    2. 
        
  2. Revisa que el dia no tenga noticias (el sistema ya lo bloquea) y marca los niveles: VWAP y sus 3 desviaciones.
    3. 
        
  3. Define 2–3 simbolos para la sesion. Menos pantallas, menos impulsos.
    4. 
      

      
Durante

      
    
        
  1. Solo entras si el checklist esta completo. Si dudas en un punto, no se cumple.
    2. 
        
  2. El tamano lo calcula el sistema. Tu decides entrada, stop y objetivo; nunca la cantidad.
    3. 
        
  3. El stop se mueve solo a favor. No se promedia, no se piramida, no se cambia de idea a mitad.
    4. 
        
  4. Despues de una perdida hay pausa obligatoria. Levantate de la silla.
    5. 
        
  5. Dos perdidas seguidas o el limite diario: se acabo el dia, aunque "veas" la siguiente.
    6. 
      

      
Despues

      
    
        
  1. Revisa cada operacion en el journal: ¿segui el plan? La nota es al proceso, no al resultado.
    2. 
        
  2. Una operacion perdedora con el plan cumplido es una buena operacion. Una ganadora rompiendo reglas es una mala.
    3. 
        
  3. Cada fin de semana: expectativa en R, % de operaciones con checklist completo y errores repetidos.
    4. 
      

      
Por que el sistema es asi

      
    
        
  • Riesgo base = el menor capital del dia. Ganar en la manana no agranda el riesgo de la tarde.
    • 
        
  • Presupuesto: si todos tus stops saltan a la vez, no puedes pasar el limite diario. La siguiente operacion se recorta sola.
    • 
        
  • Aflojar tarda 24h. La disciplina se rompe en caliente; el retraso hace que esa decision no cuente ese dia.
    • 
        
  • Guardian cada minuto: si abres por fuera, alejas el stop o agregas tamano desde la app del exchange, lo corrige o cierra.
    • 
        
  • Margen aislado y el menor apalancamiento posible: el apalancamiento no cambia el riesgo (lo fija el stop), solo acerca la liquidacion.
    • 
      

      
Lo que el sistema no puede impedir

      
    
        
  • Que operes desde otra cuenta o exchange no conectado. Conecta solo cuentas dedicadas y no tengas saldo de trading en otras.
    • 
        
  • Los ~60 s entre revisiones del guardian. Desinstala la app del exchange del telefono en horario de sesion.
    • 
        
  • Que borres las llaves o edites la base de datos a mano. Esa friccion es intencional: si llegas a eso, el problema no es tecnico.
